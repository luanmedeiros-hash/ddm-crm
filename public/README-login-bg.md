# Imagem de fundo do login

Coloque a foto da equipe aqui com o nome **`login-bg.jpg`**:

```
public/login-bg.jpg
```

A tela de login (`/login`) usa essa imagem como fundo, escurecida, com o
card de login centralizado por cima. Se o arquivo não existir, o fundo
fica em um tom escuro sólido (fallback) — sem quebrar nada.

Dica: use uma imagem larga (ex: 1920×1080) e em JPG para carregar rápido.
